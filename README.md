# MLTraining

Centro de formación intensiva de José Luis Valderrama Ampuero.

Esta versión estática se publica con GitHub Pages. Los datos de avance se guardan en el almacenamiento local de cada navegador; usa **Exportar** e **Importar** dentro de la aplicación para trasladar tus registros entre dispositivos o desde la versión anterior.

## Vista local

Abre `index.html` mediante un servidor HTTP local, por ejemplo `python -m http.server 8000`, y visita `http://localhost:8000/`.
